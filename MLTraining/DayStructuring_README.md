# Структурирование дня (текст / голос → события)

## Как работает в приложении

1. Пользователь говорит или пишет рассказ о дне.
2. `DayStructuringEngine` разбивает текст на события:
   - маркеры: «потом», «затем», перенос строки, «;»
   - время: «в 9 утра», «14:30», «утром», «вечером»
3. События сортируются **по времени**, без времени — по порядку в тексте.
4. Если не хватает данных → экран **«Уточним детали»**:
   - «Во сколько было …?»
   - «Что было раньше?» (два события без времени)
5. Далее: фото → превью → сохранение.

Голос: `SpeechDayTranscriber` (Speech framework, ru-RU).

## Create ML (следующий шаг)

Сейчас движок на правилах + `NaturalLanguage`. Для улучшения:

1. **Text Classifier** — тип фрагмента: `event` / `time` / `noise`
2. **Word Tagging** — выделение времени и действия в предложении
3. Обучить на своих примерах дневников → `.mlmodel` в таргет

После добавления модели — расширить `DayStructuringEngine.splitIntoSegments` и `extractTime`, чтобы сначала вызывать Core ML, затем fallback.
