# Create ML: классификатор вопросов к памяти

Приложение умеет отвечать на вопросы **сразу** (эвристики + поиск по событиям).  
Чтобы точнее понимать **тип вопроса** («делал ли», «когда», «сколько раз»), обучи текстовый классификатор в **Create ML** и добавь модель в Xcode.

## 1. Обучение в Create ML (macOS)

1. Открой **Create ML** → **New Project** → **Text Classifier**.
2. Импортируй файл `question_intent_training.csv` из этой папки.
3. Колонка **text** — текст вопроса, колонка **label** — метка (см. ниже).
4. Train → Export → сохрани как `MemoryQuestionIntent.mlmodel`.

### Метки (label)

| label     | Пример вопроса                          |
|-----------|-----------------------------------------|
| `didDo`   | Делал ли я бег вчера?                   |
| `whenDid` | Когда я был в спортзале?                |
| `whatDid` | Что я делал 12 апреля?                  |
| `howMany` | Сколько раз я пил кофе?                 |
| `search`  | Память про встречу с Аней              |

## 2. Добавление модели в Xcode

1. Перетащи `MemoryQuestionIntent.mlmodel` в таргет **memory**.
2. Убедись, что файл в **Target Membership** → memory.
3. Пересобери проект — Xcode скомпилирует `.mlmodelc`.

Код загрузки: `memory/ML/MemoryQuestionClassifier.swift`  
Если модели нет — используется встроенный fallback (ключевые слова).

## 3. Как работает ответ на устройстве

1. Все дни/события из SwiftData попадают в **индекс** (`MemoryKnowledgeBase`).
2. Из вопроса извлекаются **ключевые слова** («зал», «кофе», «прогулка»).
3. По индексу ищутся совпадения (текст + словарные соседи через `NLEmbedding`).
4. По типу вопроса формируется ответ на русском (`MemoryQueryEngine`).

Данные **не уходят с устройства** — всё локально.

## 4. Расширение датасета

Добавляй строки в `question_intent_training.csv` в формате:

```csv
text,label
"Ты ходил в бассейн на прошлой неделе?",didDo
```

Переобучи модель и замени `.mlmodel` в проекте.
