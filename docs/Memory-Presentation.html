Проблема

Как сейчас

  • День — обрывки без структуры
  • Дневники требуют ручного оформления
  • Поиск «когда я это делал» занимает время

Запрос

  • Рассказать день естественно
  • Получить хронологию автоматически
  • Спросить память одной фразой
  • Приватность данных

Решение

Memory превращает рассказ (голос/текст) в события с временем и фото, хранит историю на устройстве и отвечает на вопросы по всей памяти.
